# LiteBoard

LiteBoard is a tenant-aware asset and master data management platform built with Nuxt 4 and Nuxt UI.

## Setup

Install the dependencies:

```bash
pnpm install
```

## Development Server

Start the development server on `http://localhost:3000`:

```bash
pnpm dev
```

## Validation

```bash
pnpm lint
pnpm typecheck
```

## Production

Build the application:

```bash
pnpm build
```

Preview the production build locally:

```bash
pnpm preview
```
